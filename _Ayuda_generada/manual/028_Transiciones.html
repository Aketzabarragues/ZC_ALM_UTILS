Transiciones

Este bloque es el encargado de gestionar todas las transiciones entre las etapas de la secuencia del proceso.

Siempre se utilizarán las constantes de usuario creadas para este proceso para su uso en la etapa actual y en la etapa siguiente.

El primer segmento de este bloque SIEMPRE tiene que estar, este es el encargado de gestionar el arranque del proceso. Cada vez que un proceso se arranca, pasa de la etapa 0 a la etapa 1, y ya a partir de aquí pasa a la etapa que se configure en este segmento. Las marcas de ErroresComprobados y de EntidadesCargadas SIEMPRE tienen que estar.

Por norma general, siempre se intentará mantener el mismo número de segmentos por cada etapa, y su orden.

Gestión tiempo de etapa

Segmento encargado de activar/desactivar el tiempo de etapa.

La activación del tiempo de etapa, siempre se gestionará con un SET.

La activación del reset de tiempo de etapa, siempre se gestionará con un SET.

En caso de no utilizar, dejar la orden activar a RESET o el segmento vacío.

Gestión litros etapa

Segmento encargado de activar/desactivar los litros de etapa.

La activación de los litros de etapa, siempre se gestionará con un SET.

En caso de no utilizar, dejar la orden activar a RESET o el segmento vacío.

Gestión salto de etapa

Segmento encargado de gestionar los saltos de etapa.

Siempre se utiliza la variable EtapaSiguiente para el salto de etapa.

Siempre se utilizarán las constantes de proceso para las etapas.

Se puede utilizar las variables de LitrosEtapa.Cumplido o TiempoEtapa.Cumplido del proceso.

Se puede utilizar cualquier condición de salto de etapa.

Finalización del proceso

Para finalizar el proceso, siempre hay que utilizar la constante de sistema de FIN_PROCESO.
