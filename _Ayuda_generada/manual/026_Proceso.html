Proceso

  • Enclavamientos proceso
  • Alarmas proceso
  • Avisos
  • Permisos

Variables temporales

El FC de proceso tiene las siguientes variables temporales.

Enclavamientos proceso

Grupo de segmentos encargado de gestionar los enclavamientos del proceso. El enclavamiento del proceso impide que este se pueda iniciar.

Se disponen de 8 enclavamientos para poder diferenciarlos.

Hoy en día no se usa.

El modo de uso es mediante una asignación directa a la variable de los enclavamientos.

Alarmas de proceso

Grupo de segmentos encargados de gestionar las alarmas del proceso. La alarma o error del proceso, hace que este se pause.

Se disponen de 8 alarmas de proceso para su libre programación.

En el segmento principal, se realiza un reset de las alarmas, para que estas se puedan volver a generar.

El modo de uso es mediante SET, escribiendo el valor de la alarma y también el texto de error.

Avisos

Grupo de segmentos encargados de gestionar los avisos del proceso. El aviso NO realiza ninguna acción al proceso.

Se disponen de 8 avisos de proceso para su libre programación.

En el segmento principal, se realiza un reset de los avisos, para que estas se puedan volver a generar.

El modo de uso es mediante SET, escribiendo el valor del aviso y también el texto de aviso.

Permisos

Grupo de segmentos encargados de gestionar los permisos del proceso. Estos permisos son los propios del proceso.

El modo de uso es mediante asignación directa.

Permisos pulsadores extra

Grupo de segmentos encargados de gestionar los permisos y gestión de los pulsadores extras.

En cada segmento, se gestionará el permiso de cada pulsador, del mismo modo que los permisos descritos en el punto anterior.

En caso de no tener, se dejará un segmento vacío como el siguiente.

Al final de este grupo de segmentos, en el segmento “Gestión pulsadores extras”, se realizará la llamada a la función pulsador para que se gestionen.

En caso de no utilizar, se dejara el segmento vacio.

Ordenes

Grupo de segmentos encargados de gestionar las órdenes del proceso. Estas órdenes se utilizarán en caso de tener que gestionar el proceso directamente desde el PLC.

La orden de reset errores, siempre deberá tener por lo menos la marca de acuse del DB de sistema.

Agrupaciones

Grupo de segmentos encargados de gestionar las marcas de agrupaciones.

En caso de no utilizar, se dejará un segmento vacío como el siguiente.

Modos de trabajo

Grupo de segmentos encargados de gestionar las marcas de modos de trabajo.

Los modos de trabajo se intentará siempre gestionarlos mediante pulsadores.

En el primer segmento, se realizará la gestión de la marca INT del modo de trabajo.

En el siguiente segmento en SCL, se realizará la conversión de INT a las variables BOOL, las cuales serán las que se utilicen en el proceso.

En caso de no utilizar, se dejará un segmento vacío como el siguiente.

Litros etapa

Grupo de segmentos encargados de gestionar los litros de etapa el proceso.

Siguiendo la misma filosofía de encapsulamiento, en los procesos que se necesite contar totalizadores para gestionar los cambios de etapa, utilizaran las variables de “litros etapa” que se encuentran dentro del UDT del proceso.

En el primer segmento se gestionará la visibilidad de los litros de etapa, que se mostraran en HMI/SCADA. Se utilizará mediante asignación directa.

En el siguiente segmento, se gestionará la transferencia de datos del totalizador actual a la variable del proceso.

Entidades

Grupo de segmentos encargados de gestionar las capturas y liberaciones de entidades dinámicas del proceso.

Se dividen en dos subgrupos de segmentos, uno para ordenes de capturar y otro para ordenes de liberar.

Capturar

Segmentos encargados de gestionar las órdenes de captura de entidades a petición del usuario.

Siempre se utilizará mediante un SET.

Se activará la orden de capturar de la entidad deseada dentro del proceso.

Liberar

Segmentos encargados de gestionar las órdenes de liberación de entidades a petición del usuario.

Siempre se utilizará mediante un SET.

Se activará la orden de liberar de la entidad deseada dentro del proceso.

Configuración proceso

Grupo de segmentos encargados de gestionar la configuración del proceso.

En el primer segmento, se asignará el tipo de proceso.

En el siguiente segmento, se realizará la activación de las marcas de etapa.

Se escribirán mediante asignación directa.

En el siguiente segmento, se realizará la configuración de la secuencia. Este se encargará de:

  • Reinicializar la marca Proceso.VentanaAviso.Mostrar
  • Definir el nombre del proceso
  • Definir el ID
  • Definir el tiempo etapa
  • Definir los litros de etapa

En caso de querer utilizar la ventana de aviso del proceso, esta se definirá en la configuración de la secuencia.

En el siguiente segmento, se realizará la configuración del texto de cada etapa. Este se encargará de gestionar tanto el texto de la etapa actual como el del cambio de etapa.

En el siguiente segmento, se realizará la configuración de los bits de marcha del proceso. Los procesos cuentan con hasta 8 bit de marcha retardados, que se utilizaran para activaciones de dispositivos.
