DB Proceso

Cada proceso tendrá su DB asociado, siguiendo las mismas reglas de numeración de bloques. Siempre deberá tener la siguiente estructura y en este orden. Estas categorías serán comunes para todos los procesos, y son OBLIGATORIAS para todos los procesos.

Proceso

UDT principal del proceso. Contiene la estructura de datos principal de los procesos

Pulsadores

STRUCT. Contendrá pulsadores extra para el proceso. Utilizaran UDT ZC_PULSADOR.

En caso de no utilizar pulsadores extra, se deja declarado un pulsador de reserva.

Visibilidades

STRUCT. Contendrá variables auxiliares para su uso como visibilidades.

En caso de no utilizar visibilidades, dejar variables de reserva.

Pulsos

ARRAY [1..XX] OF BOOL. Array de booleanos para su uso como pulsos.

Ajustar en función del proceso.

Modo trabajo

STRUCT. Contendrá variables que indican el modo de trabajo de la maquina/proceso.

Se utilizarán variables tipo INT para su gestión bien mediante pulsadores o bien mediante asignación directa en HMI.

Se utilizarán variables tipo BOOL para su uso en el programa. De esta forma las referencias cruzadas serán más sencillas.

En caso de no utilizar modos de trabajo, dejar un booleano y un entero de reserva.

Parámetros de trabajo

STRUCT. Contendrá variables que indicaran parámetros de funcionamiento del proceso (temperaturas, valores fijos, conductividades, tiempos, etc.)

En caso de no utilizar parámetros de trabajo, dejar de reserva.

Agrupaciones

STRUCT. Contendrá variables que indican agrupaciones de etapas, modos, etc. Se utilizan para simplificar la lógica del proceso.

En caso de no utilizar agrupaciones, dejar de reserva.

Etapa

STRUCT. Contendrá variables que indican la etapa actual en la que se encuentra el proceso.

Siempre deberá de tener todas las etapas del proceso.

Estado

STRUCT. Contendrá variables que indican el estado del proceso/maquina. No confundir con el estado del proceso, esta estructura se utilizará para indicar otros estados (planta limpia, tiempos calculados, etc.)

En caso de no utilizar estados, dejar de reserva.

Auxiliares

STRUCT. Contendrá variables auxiliares para cálculos, marcas internas, variables que solo se utilizaran en el proceso.

En caso de no utilizar estados, dejar de reserva.

Extras

A continuación de estas estructuras obligatorias, se ira añadiendo las estructuras particulares de cada proceso. Se intentará mantener la misma organización y normas descritas en este manual.
