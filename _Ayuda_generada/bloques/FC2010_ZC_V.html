🔸 Lógica: IDIOMA

Este bloque se encarga de gestionar los idiomas para la generación de alarmas, leyendo la variable de configuración de idioma actual del HMI.

REGION IDIOMA
    CASE #Idioma OF
            // =============================================================================
            // ESPAÑOL
        1:
            #t_TrazaDispositivo := '';
            #t_TrazaManual := '';
            #t_TrazaAutomatico := '';
            #t_TrazaActivado := '';
            #t_TrazaDesactivado := '';
    END_CASE;
END_REGION

🔸 Lógica: MULTIPLEXADO

Gestión centralizada del Multiplexado de datos hacia las pantallas HMI. Nota estructural: Esta región contiene la lógica de primer arranque y un bucle principal que recorre todos los multiplexados activos ("N_MAX_MUX_DISP").

(El detalle del código SCL se encuentra desglosado en las sub-regiones inferiores).

↳ Sub-lógica: INICIALIZACION_ARRANQUE

Al arranque del PLC, ponemos a 0 todos los índices de los multiplexados y abortamos la ejecución de esta región.

REGION INICIALIZACION_ARRANQUE
    IF #Arranque THEN
        FOR #for_mux := 0 TO "N_MAX_MUX_DISP" DO
            "DB2010_V".Mux[#for_mux].Index :=
            "DB2010_V".Mux[#for_mux].oldIndex := 0;
        END_FOR;
        RETURN;
    END_IF;
END_REGION

↳ Sub-lógica: BUCLE_PRINCIPAL_MUX

Bucle principal de escaneo para evaluar y procesar los índices solicitados desde las pantallas HMI.

(El detalle del código SCL se encuentra desglosado en las sub-regiones inferiores).

↳ Sub-lógica: LIMITES

Antes de iniciar la lógica del multiplexado, revisamos que el índice solicitado esté dentro de los límites permitidos (0 y N_MAX_DISP_V). Si se excede, se limita y se activa el flag MaxVisible.

REGION LIMITES
    IF "DB2010_V".Mux[#for_mux].Index < 0 THEN
        "DB2010_V".Mux[#for_mux].Index := 0;
    END_IF;
    IF "DB2010_V".Mux[#for_mux].Index > "N_MAX_DISP_V" THEN
        "DB2010_V".Mux[#for_mux].Index := "N_MAX_DISP_V";
    END_IF;
    IF "DB2010_V".Mux[#for_mux].Index >= "N_MAX_DISP_V" THEN
        "DB2010_V".Mux[#for_mux].MaxVisible := TRUE;
    ELSE
        "DB2010_V".Mux[#for_mux].MaxVisible := FALSE;
    END_IF;
END_REGION

↳ Sub-lógica: CARGA_INICIAL

Carga inicial de valores del dispositivo al detectar un cambio de índice desde el HMI.

REGION CARGA_INICIAL
    IF #t_Index <> #t_oldIndex THEN
        "DB2010_V".Mux[#for_mux].V := "DB2010_V".V[#t_Index];
    END_IF;
END_REGION

Captura las órdenes y cambios de configuración realizados por el usuario en el HMI y los aplica a la válvula.

        "DB2010_V".V[#t_Index].Estado_AutoMan := "DB2010_V".Mux[#for_mux].V.Estado_AutoMan;

    // ... (Resto de órdenes y configuraciones)

↳ Sub-lógica: GESTION_CAMBIOS

Sincroniza los cambios realizados en este multiplexado con el resto de visores que tengan abierto el mismo dispositivo.

REGION GESTION_CAMBIOS
    IF "DB2010_V".Mux[#for_mux].ExisteCambio THEN
        FOR #for_mux_cambios := 0 TO "N_MAX_MUX_DISP" DO
            IF #for_mux_cambios <> #for_mux THEN
                IF #t_Index = "DB2010_V".Mux[#for_mux_cambios].Index THEN
                    "DB2010_V".Mux[#for_mux_cambios].V := "DB2010_V".V[#t_Index];
                END_IF;
            END_IF;
        END_FOR;
        "DB2010_V".Mux[#for_mux].ExisteCambio := FALSE;
    END_IF;
END_REGION

Evalúa la orden de activación basándose en si la válvula se encuentra en modo Automático o Manual.

        "DB2010_V".Agrup["DB2010_V".V[#for_i].Config_GrupoAlarma].AlgunaEnManual := TRUE;

↳ Sub-lógica: GESTION_NUEVA_ALARMA

Detección de flanco positivo de una alarma para disparar la activación de balizas o cláxones a nivel de máquina.

REGION GESTION_NUEVA_ALARMA
    IF "DB2010_V".V[#for_i].Alarmas_General AND NOT "DB2010_V".V[#for_i].Aux_oldAlarma THEN
        "DB2010_V".Agrup["DB2010_V".V[#for_i].Config_GrupoAlarma].NuevaAlarma := TRUE;
        "DB2010_V".V[#for_i].Aux_oldAlarma := TRUE;
    END_IF;
    IF NOT "DB2010_V".V[#for_i].Alarmas_General AND NOT #t_ErrorReposo AND NOT #t_ErrorTrabajo THEN
        "DB2010_V".V[#for_i].Aux_oldAlarma := FALSE;
    END_IF;
END_REGION

	            esté dentro de los límites permitidos (0 y N_MAX_DISP_V). Si se excede, se limita y se activa el flag MaxVisible. *)

	                                    IF #t_Index = "DB2010_V".Mux[#for_mux_cambios].Index THEN
	                                        "DB2010_V".Mux[#for_mux_cambios].V := "DB2010_V".V[#t_Index];

	            /// </RegionDoc>

	                IF "DB2010_V".V[#for_i].Estado_AutoMan THEN
	                    "DB2010_V".Agrup["DB2010_V".V[#for_i].Config_GrupoAlarma].AlgunaEnManual := TRUE;
	                    IF "DB2010_V".V[#for_i].Orden_ActivarManual AND #SeguridadesOK AND "DB2010_V".V[#for_i].Estado_SeguridadOk THEN 
	                        #t_Activar := TRUE;
	                    ELSE
	                        #t_Activar := FALSE;
	                        "DB2010_V".V[#for_i].Orden_ActivarManual := FALSE;
	                    END_IF;
	                ELSE
	                    "DB2010_V".V[#for_i].Orden_ActivarManual := FALSE;
	                    // ... (Lógica automática)
	                END_IF;
	            END_REGION
	                  
	            /// <RegionDoc>
	            (* Cruza la orden de activación (#t_Activar) con los finales de carrera físicos y la configuración para establecer el estado real de la válvula. *)
	            /// </RegionDoc>
	            REGION ESTADO_DEL_DISPOSITIVO
	                IF #Simulacion THEN
	                    IF #t_Activar THEN "DB2010_V".V[#for_i].Estado_Activado := TRUE; ELSE "DB2010_V".V[#for_i].Estado_Activado := FALSE; END_IF;
	                END_IF;
	                // ... (Lógica de los diferentes tipos de válvulas)
	            END_REGION
	                  
	            /// <RegionDoc>
	            (* Subsistema principal de evaluación, temporización y confirmación de fallos mecánicos de la válvula. *)
	            /// </RegionDoc>
	            REGION ERRORES
	                
	                /// <RegionDoc>
	                (* Detección instantánea (sin temporizar) de discrepancias entre la orden dada y el retorno físico esperado. *)
	                /// </RegionDoc>
	                REGION GESTION_ALARMA_INSTANTANEA
	                    // (Lógica instantánea reposo, trabajo y doble)
	                END_REGION
	                
	                /// <RegionDoc>
	                (* Aplica el tiempo de gracia (Setpoint) configurado a los errores instantáneos detectados antes de lanzar una alarma. *)
	                /// </RegionDoc>
	                REGION GESTION_TIEMPO_ALARMA
	                    // (Temporizador de alarmas)
	                END_REGION
	                
	                /// <RegionDoc>
	                (* Consolida los errores superados en tiempo y activa la alarma general del dispositivo y del grupo. *)
	                /// </RegionDoc>
	                REGION GESTION_ALARMAS                          
	                    // (Traspaso de tiempos a marcas de alarma reales)
	                END_REGION
	                
	            END_REGION
	                  
	            /// <RegionDoc>
	            (* Contabiliza maniobras para los planes de mantenimiento preventivo. *)
	            /// </RegionDoc>
	            REGION DIAGNOSIS
	                IF ("DB2010_V".V[#for_i].Estado_Activado AND NOT "DB2010_V".V[#for_i].Aux_oldActivado) OR
	                    (NOT "DB2010_V".V[#for_i].Estado_Activado AND "DB2010_V".V[#for_i].Aux_oldActivado) THEN
	                    "DB2010_V".V[#for_i].Tiempos_Ciclos += 1;
	                END_IF;
	            END_REGION
	                  
	            /// <RegionDoc>
	            (* Ataque físico a la salida de la tarjeta de periferia (POKE_BOOL) si la válvula no está en alarma. *)
	            /// </RegionDoc>
	            REGION ESCRITURA_SALIDA
	                IF "DB2010_V".V[#for_i].Config_DireccionSalidaByte >= 0 THEN
	                    IF #t_Activar AND NOT "DB2010_V".V[#for_i].Alarmas_General THEN
	                        POKE_BOOL(area := 16#82, dbNumber := 0, byteOffset := "DB2010_V".V[#for_i].Config_DireccionSalidaByte, bitOffset := "DB2010_V".V[#for_i].Config_DireccionSalidaBit, value := TRUE);
	                    ELSE
	                        POKE_BOOL(area := 16#82, dbNumber := 0, byteOffset := "DB2010_V".V[#for_i].Config_DireccionSalidaByte, bitOffset := "DB2010_V".V[#for_i].Config_DireccionSalidaBit, value := FALSE);
	                    END_IF;
	                END_IF;
	            END_REGION
	                  
	            "DB2010_V".V[#for_i].Orden_ActivarAuto := FALSE;
	            "DB2010_V".V[#for_i].Estado_Enclavado := FALSE;
	                  
	            /// <RegionDoc>
	            (* Registra en el sistema de trazabilidad del SCADA/HMI los cambios de estado (Pase a Manual) y maniobras operadas manualmente. *)
	            /// </RegionDoc>
	            REGION TRAZABILIDAD_MANUALIZACION
	                IF "DB2010_V".V[#for_i].Estado_AutoMan AND NOT "DB2010_V".V[#for_i].Aux_oldAutoMan THEN
	                    "FC8_ZC_TRAZA_REGISTRO"(FechaHora := "DB1_SYS".FechaHoraActual, Registrar := 1, Categoria := 1, Id := #for_i, User := "DB1_SYS".Usuario.Actual, Texto := CONCAT_STRING(IN1 := #t_TrazaDispositivo, IN2 := "DB2010_V".V[#for_i].Hmi_Nombre, IN3 := #t_TrazaManual));
	                END_IF;
	                // ... (Resto de trazas)
	            END_REGION
	                  
	            "DB2010_V".V[#for_i].Aux_oldActivado := "DB2010_V".V[#for_i].Estado_Activado;
	            "DB2010_V".V[#for_i].Aux_oldAutoMan := "DB2010_V".V[#for_i].Estado_AutoMan;
	                  
	        ELSE
	                  
	            // =============================================================================
	            // DISPOSITIVO NO HABILITADO
	            "DB2010_V".V[#for_i].Alarmas_General := FALSE;
	            // ... (Reset del resto)
	                  
	        END_IF;
	              
	        /// <RegionDoc>
	        (* Compacta el estado de alarmas, manual, etc. en una única variable 'Word' para ahorrar recursos en la comunicación HMI. *)
	        /// </RegionDoc>
	        REGION GESTION_HMI
	            "DB2010_V".V[#for_i].Hmi_Estado.%X0 :="DB2010_V".V[#for_i].Config_Habilitar;
	            "DB2010_V".V[#for_i].Hmi_Estado.%X1 := "DB2010_V".V[#for_i].Estado_AutoMan;
	            // ... (Resto de mapeos de bits)
	        END_REGION
	              
	        /// <RegionDoc>
	        (* Detección de flanco positivo de una alarma para disparar la activación de balizas o cláxones a nivel de máquina. *)
	        /// </RegionDoc>
	        REGION GESTION_NUEVA_ALARMA
	            IF "DB2010_V".V[#for_i].Alarmas_General AND NOT "DB2010_V".V[#for_i].Aux_oldAlarma THEN
	                "DB2010_V".Agrup["DB2010_V".V[#for_i].Config_GrupoAlarma].NuevaAlarma := TRUE;
	                "DB2010_V".V[#for_i].Aux_oldAlarma := TRUE;
	            END_IF;
	            IF NOT "DB2010_V".V[#for_i].Alarmas_General AND NOT #t_ErrorReposo AND NOT #t_ErrorTrabajo THEN
	                "DB2010_V".V[#for_i].Aux_oldAlarma := FALSE;
	            END_IF;
	        END_REGION
	              
	    END_FOR;
	          
	    // =============================================================================
	    //  ACUSE DE NUEVAS ALARMAS
	    IF #Ack THEN
	        FOR #for_i := 0 TO "N_MAX_DISP_AGRUP" DO
	            "DB2010_V".Agrup[#for_i].NuevaAlarma := FALSE;
	        END_FOR;
	    END_IF;
	
	END_REGION
	      
END_FUNCTION
