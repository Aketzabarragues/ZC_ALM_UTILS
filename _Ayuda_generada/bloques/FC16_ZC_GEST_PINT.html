Descripción General

Nombre: FC16_ZC_GEST_PINT Descripcion: Funcion para gestion de trazabilidad de parametros reales

Notas y Restricciones:

Software: TIA Portal 18 Restricciones: PLC serie 1200/1500

🔸 Lógica: CALCULO_LIMITES_ARRAY

Este bloque se encarga de calcular el limite del array de entrada. Solo se calcula del array de parametros, ya que el DB usa la misma constante N_MAX para dimensionarlo todo

REGION CALCULO_LIMITES_ARRAY
    #t_IndiceInferior := LOWER_BOUND(ARR := #PInt, DIM := 1);
    #t_IndiceSuperior := UPPER_BOUND(ARR := #PInt, DIM := 1);
END_REGION

🔸 Lógica: PRIMER_ARRANQUE

Este bloque se encarga de actualizar los valores actuales como valores anteriores en el arranque de la CPU. Esto se realiza ya que los valores anteriores no son remanentes, para optimizar la memoria del PLC.

REGION PRIMER_ARRANQUE
    IF #PrimerCiclo THEN

        FOR #for_i := #t_IndiceInferior TO #t_IndiceSuperior DO
            #ValorAnterior[#for_i] := #PInt[#for_i].Valor;
        END_FOR;

        //  Salimos inmediatamente de la funcion, para realizar la gestion de los parametros con la CPU arrancada
        RETURN;

    END_IF;
END_REGION

🔸 Lógica: GESTION_PARAMETROS

Este bloque se encarga de gestionar los cambios de valor de los parametros. Si detecta un cambio, lanza la traza y actualiza el valor anterior.

REGION GESTION_PARAMETROS
    FOR #for_i := #t_IndiceInferior TO #t_IndiceSuperior DO

        //  En caso de detectar cambio de valor
        IF #PInt[#for_i].Valor <> #ValorAnterior[#for_i] THEN

            //  TODO
            //  Lanzamos la trazabilidad
            "FC8_ZC_TRAZA_REGISTRO"(FechaHora := #FechaHora,
                                    Registrar := 1,
                                    Categoria := "TRZ_CAT_5_PREAL",
                                    User := #Usuario,
                                    Codigo1 := 1,
                                    Codigo2 := 1,
                                    Codigo3 := 1,
                                    Texto := '');

            //  Actualizamos el valor anterior
            #ValorAnterior[#for_i] := #PInt[#for_i].Valor;

        END_IF;

    END_FOR;
END_REGION

   END_VAR

	    FOR #for_i := #t_IndiceInferior TO #t_IndiceSuperior DO
	        
	        //  En caso de detectar cambio de valor
	        IF #PInt[#for_i].Valor <> #ValorAnterior[#for_i] THEN
	            
	            //  TODO
	            //  Lanzamos la trazabilidad

	                                    Codigo3 := 1,
	                                    Texto := '');
	            
	            //  Actualizamos el valor anterior
	            #ValorAnterior[#for_i] := #PInt[#for_i].Valor;
	            
	        END_IF;
	        
	    END_FOR;
	    
	END_REGION
	
	
END_FUNCTION
